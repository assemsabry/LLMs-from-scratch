# 20. Learning Roadmap Order

Do not jump straight into building Large Language Models. Follow this sequential path to avoid overwhelming frustration.

---

### Step 1: The Foundations (Weeks 1-4)
1.  Learn Python to an intermediate level.
2.  Master Pandas and NumPy.
3.  Review Calculus (Derivatives, Chain Rule) and Linear Algebra (Matrices, Dot Products).

### Step 2: Classical ML (Weeks 5-8)
1.  Study the math behind Linear and Logistic Regression.
2.  Learn Random Forests and Gradient Boosting (XGBoost).
3.  Implement these algorithms using Scikit-Learn.
4.  Master Model Evaluation (Cross-validation, F1 Score) and Feature Engineering.

### Step 3: Deep Learning Basics (Weeks 9-12)
1.  Learn PyTorch. (Do not start with TensorFlow).
2.  Build a Multi-Layer Perceptron (FNN) from scratch.
3.  Understand the math of Backpropagation and Loss Functions.
4.  Build a CNN for Image Classification.

### Step 4: NLP and Transformers (Weeks 13-16)
1.  Understand Embeddings and Tokenization.
2.  Study the "Attention Is All You Need" paper.
3.  Build a basic Transformer.
4.  Learn the HuggingFace library.

### Step 5: Advanced LLMs & MLOps (Weeks 17+)
1.  Learn PEFT and LoRA fine-tuning.
2.  Build RAG systems.
3.  Learn containerization (Docker) and deployment.
