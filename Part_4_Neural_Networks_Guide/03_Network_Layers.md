# 3. Neural Network Layers

Neurons are organized sequentially into distinct layers to form a complete network.

---

## 3.1 Input Layer
*   It receives the raw data.
*   It performs absolutely no computation or learning.

## 3.2 Hidden Layers
*   This is where the actual data processing, feature extraction, and learning occurs.
*   It is the most critical and complex part of the network. Deep learning refers to networks with multiple hidden layers.

## 3.3 Output Layer
*   It provides the final prediction or result.
*   The structure of this layer depends entirely on the specific task (e.g., a single continuous number for regression, or multiple probabilities for classification).
