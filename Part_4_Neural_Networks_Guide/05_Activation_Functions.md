# 5. Activation Functions

Activation functions introduce non-linearity to the network, allowing it to learn complex patterns instead of just straight lines.

---

The most important activation functions are:

*   **ReLU (Rectified Linear Unit):** The most widely used activation function in modern deep learning hidden layers.
*   **Sigmoid:** Typically used for binary classification outputs (squashes values between 0 and 1).
*   **Tanh:** Used to center outputs between -1 and 1.
*   **Softmax:** Used in the final output layer for multi-class classification (turns raw logits into probabilities that sum to 1).
