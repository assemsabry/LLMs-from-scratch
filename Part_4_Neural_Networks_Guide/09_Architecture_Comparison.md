# 9. Architecture Comparison

A quick reference table to understand when to use which type of neural network.

---

| Type | Best Used For | Power / Complexity |
| :--- | :--- | :--- |
| **FNN** | Tabular Data | Simple |
| **CNN** | Images | Extremely Powerful |
| **RNN** | Sequences | Medium |
| **LSTM** | Sequences | Powerful |
| **Transformer** | NLP & LLMs | The Most Powerful |
