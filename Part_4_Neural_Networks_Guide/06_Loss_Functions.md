# 6. Loss Functions

The loss function calculates how wrong the model's predictions are compared to the actual true answers.

---

Different tasks require different ways to measure error:

*   **MSE (Mean Squared Error):** The standard loss function used for regression tasks (predicting continuous numbers).
*   **Cross Entropy:** The standard loss function used for classification tasks (predicting categories or words).
*   **KL Divergence:** Used to measure how one probability distribution differs from a second, reference probability distribution.
