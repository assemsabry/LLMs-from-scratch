# 1. The Basic Idea of Neural Networks

At its core, a neural network is a mathematical function approximator. Its purpose is to learn the underlying mapping between inputs and outputs.

$$y = f(x; \theta)$$

Where:
*   **$x$** = Inputs (The data fed into the network)
*   **$\theta$** = Weights and Bias (The parameters the network learns)
*   **$f$** = The Neural Network function itself
*   **$y$** = The predicted output
